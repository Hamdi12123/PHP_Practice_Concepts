# PHP Practice Concepts - Home.php

This repository or file is designed to learn the basics of **PHP**, specifically control structures and loops.

## Code Sections Included:

1. **If Statement:**
   - Checks the current month (`$month`). If it is "March", it outputs the message `"it's spring time"`.

2. **If-Else Statement:**
   - Evaluates a student's marks (`$marks`). If they are greater than or equal to 50, it displays `"pass"`, otherwise it displays `"do not pass"`.

3. **For Loop:**
   - Generates a multiplication table for the number 12, running from 1 to 12.

4. **While Loop:**
   - Prints numbers starting from 1 up to 15, separated by commas (`,`).

1. Place this file inside the **`htdocs`** folder of your **XAMPP** directory.
